# Public data and source notice

The public demo uses **Chen, D. (2015). Online Retail [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33**. The repository's [dataset page](https://archive.ics.uci.edu/dataset/352/online+retail) states **Creative Commons Attribution 4.0**, permitting sharing and adaptation with attribution. [Licence](https://creativecommons.org/licenses/by/4.0/).

Changes made: UK-only positive recorded sales; cancellation/non-product filtering; duplicate removal in the used transaction columns; daily aggregation; training-only selection of 90 products; absent product-days filled with zero; forecasts and simulations generated under the frozen protocol. The public artifact contains selected daily aggregates and predictions, not raw invoices, customer IDs, customer-level records or descriptions. Derived data retain CC BY 4.0 attribution. No endorsement by UCI or the original data creator is implied.

The original M5 result bundles remain unchanged in the private local working project. Those ZIPs contain observed sales and history as well as predictions. Their redistribution terms could not be confirmed from the accessible Kaggle rules page in this session, so they are excluded from the public repository. This is an unresolved permissions check, not a conclusion that every M5-derived result is prohibited. Public documentation may discuss aggregate measured M5 findings with attribution. Do not upload the complete local release ZIP to GitHub.

The public source contains no credentials, private machine paths, raw M5 data, environment folders or private handoff files. Code is provided for inspection; third-party data and dependency licences remain separate. No blanket licence is applied to original M5 data or third-party material.
